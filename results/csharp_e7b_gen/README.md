## 못 한 것·참고
- 재생 벤치는 읽기를 쉬지 않고 연달아 합니다. 실제 게임처럼 읽기 사이에 CPU 작업이 있으면 선행 읽기가 앞설 틈이 생길 수 있으나 이번에는 측정하지 못했습니다.
- 측정 중 다른 python 프로세스가 떠 있어 learn 은 `--seconds 45` 에서 끝났습니다(양 팔에 같은 영향).
- 개선 방향 제안(코드는 건드리지 않음): 순차 판정을 더 엄격하게(연속 N회 이상), 선행 읽기 총량을 요청 양에 맞춰 제한, 게임 읽기와 겹치면 양보.
