## 판정
**stream 모드 기본 켬은 타당하지 않습니다.** 기준(1번 해 없음 B ≥ A×0.95, 2번 B ≥ A×1.10) 중 1번을 통과하지 못했습니다.
- 1번 fpset 포화: B 가 A 보다 20% 느립니다(0.80). 선행 읽기 약 2 GB 가 재생의 읽기와 디스크를 다퉜습니다(적중 약 50%인데도 느림). 포화 재생이 learn 이 노려야 할 조건은 아니지만 "해 없음" 기준을 못 맞춥니다.
- 2번 fpset 틈: 중앙값 배수 1.10 으로 기준 경계이지만 B 3회가 80.9/46.7/38.4 s 로 크게 흔들립니다(첫 회는 A 보다 34% 느림). 적중률은 59~69%로 높아졌고 B2/B3 는 A 보다 빠르나(각 -9%, -22%), 3회로는 이득이라 단정하기 어렵습니다.
- 3번 Frostpunk 연속 틈(참고): 0.91, 이득 없음. 선행 읽기 3.2~3.4 GB 는 재생 요청(2.0 GB)의 1.6배라 읽기 낭비가 큽니다.
- 이전 빌드(틈 전용) 대비 적중률은 13~17% → 59~73%로 크게 올랐지만 선행 읽기 총량이 요청량보다 많아 디스크를 더 오래 점유합니다. 총량 제한(요청량 이내, 예: 파일의 남은 부분만 + 상한)과 게임 읽기 우선 양보가 필요해 보입니다.
