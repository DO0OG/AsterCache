## 판정
**bounded 기본 켬은 아직 타당하지 않습니다.** 주 근거(fpset 틈 재생)는 1.13 으로 기준 1.10 을 넘었지만, 해 없음 기준(포화 ≥0.95)을 못 맞췄습니다(0.90).
- 포화 재생: B 가 A 보다 약 11% 느립니다(0.90). 그래도 stream(0.80)보다 나아졌고 총량이 요청량과 같아졌습니다. 적중률은 31~36% 로 낮습니다.
- 틈 재생(fpset): 중앙값 1.13, B 3회 모두 A 중앙값 이하이거나 근처입니다(40.4/49.0/41.7 vs 47.2/59.3/42.1). 다만 A 가 흔들려(42~59 s) 3회로는 이득의 크기를 단정하기 어렵습니다. 이전 빌드(stream)의 B 80.9/46.7/38.4 보다 변동이 줄었습니다.
- Frostpunk 연속 틈: 0.84, 이득 없음(이미 연속이라 앞서 읽을 여지가 작음. learn 의 대상 조건이 아님).
- 개선 여지: 포화에서 해를 줄이려면 양보 구간(50 ms)과 선행 단위 조정, 또는 포화 감지 시 중단 규칙이 필요해 보입니다.
